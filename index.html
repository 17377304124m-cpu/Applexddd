            关于 MingJun

            MingJun 2.0.7

            • 新增小P 对话、历史记录、模型 API 配置和记忆库。
            • 日历与课表集中在「信息」，「工具」汇集账号、待办、资料库和网址。
            • 新增黑白主题及包含新资料的一键导出，支持导入旧版备份。
            • 统一底栏、目录和操作图标，更新小P 标志。
            • 小P 直接连接 DeepSeek，在配置页填写 API Key 即可使用。
            • 小P 回复支持复制文本和图片，修复历史侧栏的焦点黑框和手机键盘遮挡。
            • 小P 支持流式思考和回复，历史与新回复统一排版。模型菜单缩小，聊天头像单独显示。
            • 输入框上方可切换 DeepSeek Flash 和 V4 Pro；侧栏可新建对话和右滑删除历史。
