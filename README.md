# 明军的生活助理（Applexddd）

- **项目版本**：v1.11
- **项目目标**：成为明军的个人生活助理，帮助记住好友农历生日与重要事件、查看日常课表、记忆账号、管理待办。本地双击即可使用，并支持 iPhone Safari“添加到主屏幕”。

## 当前进度

v1.11 已于 2026-11-09 发布上线，功能提交为 `7e766ff`。线上首页与19个运行资源均与本地一致，线上真实下载及独立浏览器环境恢复全部数据验证通过。个人页增加导出和导入入口，采用本机 JSON 文件迁移，不增加账号、云同步或第三方服务；备份包含账号密码及2FA密钥，界面提示妥善保管。

- 生活日历：周一为每周起点；显示公历、农历、今天与选中日期，标记常见公历纪念日、春节/元宵/端午/七夕/中秋/重阳等农历节日、母亲节与父亲节；2026、2027 年包含清明节及官方放假与补班标记。点击日期查看完整节日列表。

- 事件：记录名称、公历日期及备注，按日期排序，支持关键词搜索与日期跳转。同一天可显示多个生日与事件，删除需确认。

## 使用方法

- **电脑本地**：双击 `index.html` 即可。
- **换手机备份**：旧手机 → 个人 → 数据备份 → 一键导出，保存JSON文件并传至新手机；新手机打开同一网站 → 个人 → 导入恢复 → 选择备份 → 核对数量 → 恢复并替换。新手机若已有数据，先另行导出保留；备份文件未加密，包含账号密码和2FA密钥。
- **快速记日程**：主页日历下输入文字后点击“识别日程”，或点击“添加图片”直接识别；核对事项、日期、时间及原文备注，再点击“加入日历”。多条事项可逐条修改或移除，识别不准时可手动补充；图片文字会追加到输入区，未确认前不会添加事件。
- **手机滑动**：工具/信息页内容区左右滑动切分类，日历日期格左右滑动换月份；输入区及系统边缘不接管手势。
- **添加账号/链接**：信息 → 账号或链接 → 标题右侧“＋” → 填写并保存；关闭弹窗不会添加记录。
- **复制与链接排序**：点击链接右侧复制图标复制网址；长按链接再上下拖动，或用出现的上移/下移按钮调整顺序。账号的复制图标按蓝色账号/紫色密码/绿色验证码对应。
- **课表图片导入**：工具 → 课表 → 图片导入 → 选择 PNG/JPG/WEBP 截图 → 开始识别 → 对照原图核对/补齐 → 确认更新课表。保存前会再次确认替换，不会自动覆盖。
- **课表修改**：工具 → 课表 → 修改。节次支持 `1-2`、`1,3`；周次支持 `1-16`、`1-16单周`、`2,4,6`。星期、节次及周次缺失时必须补齐。
- **iPhone 添加到主屏幕**（需要手机能访问到页面）：
  1. Safari 打开 https://17377304124m-cpu.github.io/Applexddd/
  2. 点分享按钮 →"添加到主屏幕"→ 桌面出现"明军"图标
  3. 局域网备用方式：本目录运行 `python -m http.server 8000`，手机访问 `http://<电脑IP>:8000`

## 图片识别能力与限制

- 采用浏览器本机 OCR，不向识别服务上传图片；网络请求用于下载 Worker、WASM 和中文模型。已有主页、生日和账号功能不依赖这些在线资源。
- 已验证带标签的课程列表，以及具有明确星期表头、课程块内明确节次与周次的格子课表。无法确认的信息留空，用户核对后才能导入；校验不代表能发现所有识别错误。
- 暂不支持 PDF、多张截图合并及通过合并单元格高度推算节次。节次具体作息时间仍沿用 `app.js` 中当前学校的 `PERIODS` 配置，不从图片自动修改。
- 本地文件和 Edge 桌面浏览器已实测；真实 iPhone Safari 尚未测试。
