- **项目版本**：v2.0
- **项目目标**：通过小P 对话、日历与课表、待办、账号和资料库管理个人信息，支持 iPhone Safari“添加到主屏幕”。

## 已完成内容

- 任务：与小P 多轮对话，左上角打开历史记录，新建或恢复本机对话。在“我的 → 记忆库”保存的内容会随每次消息交给模型，作为首条系统指令。
- 信息：日历与课表切换。生活日历可查看已有生日和事件，录入入口位于“添加记录”。
- 生活日历：周一为每周起点；显示公历、农历、今天与选中日期，标记常见公历纪念日、春节/元宵/端午/七夕/中秋/重阳等农历节日、母亲节与父亲节；2026、2027 年包含清明节及官方放假与补班标记。点击日期可查看节日简介和个人安排。
- 好友生日：姓名、农历月份/日期、闰月标记及备注。每年按农历换算，只显示一次；三十遇小月按廿九，闰月生日在无对应闰月年份按普通月。
- 事件：记录名称、公历日期及备注。选中日期可同时查看这一天的生日与事件。
- 信息页课表：支持图片识别后核对导入，以及手动修改已保存课程；默认收录原 2026–2027 学年第一学期 · 武鸣校区第10周起课程，进入时按当前日期定位。跨境电商第10周 A-306、之后 B412 的原有特例在编辑保存时会拆成两条对应周次记录保留。
- 工具：由目录进入账号、待办、资料库、网址。账号支持编辑、密码显隐、一键复制、2FA/TOTP。资料库支持新增、编辑、删除文字笔记和 HTTP(S) 链接。
- 我的：个人资料、一键导出与导入、黑白主题、模型 API 配置、记忆库和版本说明。
- iOS 主屏幕支持：`apple-touch-icon`、`apple-mobile-web-app-capable`、`manifest.json` 全套配置
- 运行时用户数据存于浏览器 localStorage，可手动导出本机备份文件；日历不调用在线接口。本地文件可离线使用，线上页面尚未设置离线缓存。

## 使用方法

- **电脑本地**：双击 `index.html` 可浏览个人资料和工具。使用小P 时，打开 GitHub Pages 线上网页并配置 DeepSeek。
- **换手机备份**：在两台手机分别打开“我的 → 一键导出与导入”。从旧手机导出 JSON 文件，在新手机选择文件，核对内容后确认恢复。已有资料可先另行导出。备份含账号密码和 2FA 密钥，应私下保管。DeepSeek API Key 仅在当前页面的内存中使用。
- **生日和事件**：在“信息 → 日历 → 添加记录”中新增，事件只需填写名称和日期，备注可选。点击月历日期，在日期安排卡片查看这一天的记录。
- **快速记日程**：在“添加记录”输入文字并点“识别日程”，或点击“添加图片”直接识别。核对事项、日期和可选备注，再点击“加入日历”。图片文字会追加到输入区，未确认前不会添加事件。
- **手机滑动**：信息页内容区左右滑动切换日历和课表，日历日期格左右滑动换月份。
- **添加账号或网址**：工具 → 账号或网址 → “＋” → 填写并保存。
- **修改账号**：工具 → 账号 → 点击目标账号右侧的修改图标 → 调整名称、账号、密码或 2FA 密钥 → 保存修改。
- **复制与链接排序**：点击链接右侧复制图标复制网址；长按链接再上下拖动，或用出现的上移/下移按钮调整顺序。账号卡片的复制图标以深青、暖棕和绿色分别对应账号、密码和验证码。
- **课表图片导入**：信息 → 课表 → 图片导入 → 选择 PNG/JPG/WEBP 截图 → 开始识别 → 对照原图核对或补齐 → 确认更新课表。
- **课表修改**：信息 → 课表 → 修改。节次支持 `1-2`、`1,3`，周次支持 `1-16`、`1-16单周`、`2,4,6`。星期、节次及周次缺失时必须补齐。
- **待办归档**：勾选完成后移到末尾，满7天后收进“已归档（数量）”；点击展开查看，取消完成会回到未完成清单首条。
- **当天课表**：进入“信息 → 课表”自动显示当天教学周及星期。当前日期基准用于现有学期。
- **iPhone 添加到主屏幕**（需要手机能访问到页面）：
  1. Safari 打开 https://17377304124m-cpu.github.io/Applexddd/
  2. 网页更新后，点分享按钮 → “添加到主屏幕” → 桌面出现 MingJun 图标
  3. 局域网备用方式：本目录运行 `python -m http.server 8000`，手机访问 `http://<电脑IP>:8000`

## 小P 模型配置

1. 在 [DeepSeek 开放平台的 API Keys](https://platform.deepseek.com/api_keys) 创建个人 API Key。
2. 打开 [MingJun 网页](https://17377304124m-cpu.github.io/Applexddd/)，进入「我的 → 配置 → 添加方案」。模型默认 `deepseek-flash`，如需修改，请填写 [DeepSeek 官方模型 ID](https://api-docs.deepseek.com/zh-cn/)。
3. 填写 API Key 并保存，回到「任务」发送消息。刷新后，进入「我的 → 配置 → 编辑」为原方案重新填写 API Key。

网页直接调用 DeepSeek 官方 Chat Completions 接口。每次发送会附带当前对话上下文和「记忆库」中最新保存的指令。方案名称、模型 ID、记忆和历史保存在当前浏览器。API Key 仅在当前页面内存中使用，不进入备份。

## 图片识别能力与限制

- 采用浏览器本机 OCR，不向识别服务上传图片；网络请求用于下载 Worker、WASM 和中文模型。已有主页、生日和账号功能不依赖这些在线资源。
- 已验证带标签的课程列表，以及具有明确星期表头、课程块内明确节次与周次的格子课表。无法确认的信息留空，用户核对后才能导入；校验不代表能发现所有识别错误。
- 暂不支持 PDF、多张截图合并及通过合并单元格高度推算节次。节次具体作息时间仍沿用 `app.js` 中当前学校的 `PERIODS` 配置，不从图片自动修改。
- 本地文件和 Edge 桌面浏览器已实测；真实 iPhone Safari 尚未测试。
